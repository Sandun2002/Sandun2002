I'm a full-stack software engineer and Computer Science student at Cardiff Metropolitan University. I enjoy building digital products end to end: shaping the architecture, writing maintainable APIs, designing responsive interfaces, and deploying software that people can actually use.

My strongest focus is the intersection of Python / FastAPI, TypeScript / Next.js, and data-driven systems. I care equally about what happens behind the API and what users experience on screen.
- I build: full-stack web applications, REST APIs, AI-enabled products, and interactive experiences.
- I optimize for: thoughtful architecture, performance, maintainability, and reliable delivery.
- I'm exploring: cloud-native infrastructure, AI/ML integration, and scalable backend design.
- I'm open to: remote engineering roles, freelance projects, and meaningful collaborations.
My approach: Keep the architecture intentional, the interfaces intuitive, and the code easy for the next developer to understand.
